# [App Name] – Bristol City Council Pilot App

A pilot Android application for **Bristol City Council**, exploring how selected council services currently delivered through [bristol.gov.uk](https://www.bristol.gov.uk/) can be delivered more effectively on mobile devices.

Developed for **UFCF7H-15-3 Mobile Applications (2026/27)** at UWE Bristol.
